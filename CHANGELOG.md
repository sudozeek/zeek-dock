# Changelog

## 0.1.0

- Set fresh dock defaults to a transparent, floating Flat2D panel with the task manager enabled and optional applets hidden.
- Add task-manager settings for click-to-minimize and scroll-to-cycle behavior.
- Add configurable hover preview cards using KWin's ScreenShot2 D-Bus interface; previews are disabled by default.
- Add task-manager preview controls and a KWin restricted-interface declaration to the generated desktop entry.
- Rebrand the installed desktop entry and application window as Zeek Dock while retaining the `zeek-dock` executable name.
